# Vim on the RP2350

This is the terminal-only tiny build of Vim 9.2.0943. It supports modal
editing, undo, search and substitution. Use `:help`, `:help quickref` or
`:help motion` for the bundled help. The build omits syntax highlighting
and the plugin and filetype runtime. Searches and substitutions use Vim's
backtracking engine. The NFA engine is omitted.

Copy this directory from the release extras ZIP to the board's SD card.
Use the `./vim` launcher to run the included binary with its runtime files.

```sh
cd /mnt/sd/extras/vim
./vim filename
./smoke.sh
```

## Building from source

From the extras directory on the board, run:

```sh
./build.sh
./smoke.sh
```

The board's bundled `cc` preprocesses, compiles, and links Vim. The build
passes an SD scratch directory to TinyCC through `TCC_LINK_SCRATCH` for the
final link. This requires the bundled toolchain with the
[low-memory linker patch](../../tcc/patches/0019-armv7m-spill-link-text-to-scratch.patch).

The release ZIP uses GCC for the smaller executable. The same sources also
build with the project's ARMv7-M cross-TCC. From the repository root, with
the [project toolchains](../../README.md) built, run:

```sh
tcc/run-host.sh sh /native/tcc/extras.sh
tcc/run-host.sh cat /work/tcc-extras/src/vim/vim.bin > extras/vim/vim.bin
```

Copy the directory with the resulting `vim.bin` to the SD card and run it
with `./vim`.

## Source and license

The C sources and runtime files come from upstream Vim
[v9.2.0943](https://github.com/vim/vim/tree/v9.2.0943), under the
[Vim license](LICENSE). Only the files needed for the tiny build and its
core help are included. The ARM musl configuration was generated by the
Buildroot Vim recipe with `--with-features=tiny --without-x --enable-gui=no
--disable-nls`. The board build supplies its own `src/pathdef.c` and uses
the ncurses 6.6 [termcap header](src/compat/termcap.h) with the board's
static ncurses library. Vim includes the [libxdiff header](src/xdiff/xdiff.h)
under the [LGPL-2.1-or-later](src/xdiff/COPYING).
